Peach Assist

Everything it does

A chat and workspace for a home or a small office that runs on your own computer, keeps everything on that computer, and looks after itself.

First run

  • A guided setup before anything else is reachable
  • Asks whether it is for a household or a business, and speaks accordingly
  • Presets so it arrives configured, not blank
  • Choose which optional features you want at the start
  • Picks the default colour theme
  • Refuses the first setup if it is attempted from outside your own network
  • A working install is never mistaken for a new one
  • You can run setup again later if you change your mind

Chat

  • Rooms and group chats, with named groups you can create, join and leave
  • Direct one-to-one conversations
  • Threaded replies
  • Edit or delete a message after sending
  • Pin an important message
  • Polls with live results
  • Photos, camera capture, freehand drawing and cropping
  • Typing indicators and presence — online, away, busy, idle, offline, last seen
  • Unread markers, muting, and archiving finished chats
  • Search across names, messages and attachments
  • Messages that must be acknowledged as read
  • Off-the-record conversations
  • Reminders you set for yourself
  • Private notes kept alongside the chat
  • Canned replies and quick commands
  • Email yourself a transcript
  • A simple guest page for someone invited in from outside

People and access

  • Accounts with display names and roles, including an administrator
  • Two-factor sign-in
  • Magic-link sign-in, no password needed
  • Invite links, plus inviting a client or outsider
  • Blocking someone and managing the block list
  • A sign-in log: who, from where, and when
  • Import a directory of people from a file
  • Departments, managers, and who belongs where
  • Rules for who may post and who sees admin areas
  • A full record of changes made
  • An abuse-report letter you can generate
  • Optional self sign-up, off unless you turn it on

Work tools

  • Tasks — assign, prioritise, set dates, mark done, see your own
  • Peach Wall — a shared board of posts, replies, likes and polls
  • Notes — keep them private or share them
  • Peach Drive — files and folders, uploads, sharing, versions
  • Mail — an inbox inside the app, with attachments
  • Calendar — meetings, a calendar other software can subscribe to, and importing an existing one
  • Time off — request, approve, see who is away, track days taken
  • Public holidays you can add and manage
  • Helpdesk — support tickets for administrators
  • Hours — time tracking, with reports on hours and on chat activity

Switching things off

  • Search history
  • Archived chats
  • Sticky notes
  • Reminders
  • Tasks
  • Peach Wall
  • Calendar
  • Time off
  • Drive
  • Mail
  • Helpdesk
  • Self sign-up
  • Invites
  • Off means gone — the screens and the way in both disappear

Reaching it from outside

  • Three ways to be reachable: through a VPN, by asking the router to open the door, or by setting it up yourself
  • The VPN route is the default and keeps your home address private
  • The router route opens the door itself, and closes it again when asked
  • Dynamic DNS built in: No-IP, DuckDNS, or your own update address, with a test button
  • Your web address is pointed at the connection you choose, never at your raw home address
  • A one-press network refresh, without restarting the messenger
  • Secure web pages using your own certificate
  • A firewall check, so you find out before a visitor does
  • A status view of how the outside world sees you

Certificates that renew themselves

  • Free trusted certificates, issued and renewed automatically
  • Ownership proved through your domain's records, so no port has to be open for it
  • Renews on its own before it expires; a test can be forced at any time
  • Emails you the result either way
  • Restarts the messenger afterwards so the new certificate is in use
  • Can also be done by hand with a single record, if you prefer

Looks after itself

  • Starts with the computer, out of sight, with no window left open
  • Only ever one copy runs
  • If it stops, it starts again — waiting longer each time if it keeps failing, so it cannot thrash the machine
  • Checks it is running the right build before it starts
  • If its own files have been changed, it rebuilds itself and carries on
  • If it cannot put itself right, it says so — it stops, writes down why, and tells you by email rather than pretending to work
  • Keeps a log of all of it you can read

The admin panel

  • An overview of the server and its status
  • People: create, edit, set roles, reset access
  • Departments and who belongs to them
  • Time off: approve or decline
  • Activity: changes made, sign-ins, and reports
  • Server: port, firewall check, public address
  • Dynamic DNS settings
  • The way in from outside
  • A network refresh
  • Backups: back up now, restore, and rules for clearing old data
  • Turn optional features on or off
  • Who is allowed to post
  • Keys for other software to connect, with a stable interface
  • An operator view of every connected client and every room
  • Blocking, the abuse letter, and a reload control
  • Help, with a printable manual

Look and feel

  • Four colour themes — sunset, forest, violet and blue
  • Dark mode
  • Each person picks their own; the server sets the default
  • Wording that suits a household or an office
  • Works on a phone as well as a desktop

How it runs

  • One program on one computer, with no cloud service in the middle
  • Everything kept locally: messages, files, settings
  • Pages update live, without refreshing
  • Simple launchers to start, stop and restart it
  • Survives a crash, a closed window or a reboot
  • Runs on Windows today; very little ties it there
